# ☢️ Vault-Tec XP Calculator — Fallout 76

A PIP-Boy styled web tool to calculate your Experience Points in Fallout 76, taking into account food bonuses, mutations, perk cards, team buffs, and more.

## ⚠️ First Release Notice

This is the **first public release (v1.0.0)** of the calculator. While core functionality has been tested, some values or interactions may not perfectly reflect in-game behavior. **Bugs are expected** — if you spot anything off, feel free to open an issue or report it.

Thanks for your patience, and stay rad! ☢️
